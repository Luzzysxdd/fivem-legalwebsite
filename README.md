## 📌 Proje Hakkında

Bu proje, Blaine County Sheriff Office (BCSO) ve benzeri FiveM / Roleplay kolluk kuvveti toplulukları için sıfırdan özel olarak tasarlanmış ve kodlanmış modern bir kurumsal web platformudur. 

Dark glassmorphism estetiği, altın ve lacivert emniyet tonları, animasyonlu arayüz geçişleri ve kapsamlı komuta yönetim paneliyle eksiksiz bir deneyim sunar.

---

## ✨ Temel Özellikler

- 🏛️ **Modern & Prestijli Arayüz:** Emniyet temalı altın/lacivert şık tasarım, cam efektleri (glassmorphism) ve mobil uyumlu responsive yapı.
- 📋 **Canlı Personel Kadrosu:** Rütbelere ve birimlere göre filtreleme, aktiflik durumu, yaka numarası ve rozet sistemi.
- ⚖️ **Ceza Kanunu (Penal Code):** Maddelere göre anlık arama, filtreleme, hapis ve para cezası detayları.
- 🏢 **Departman Birimleri (Divisions):** SWAT, Trafik, Dedektiflik, K9, Havacılık ve Komuta kadrosu özel tanıtım sayfaları.
- 📝 **Online Başvuru Sistemi:** Adayların departmana hızlı ve düzenli başvuru yapabilmesi için interaktif form.
- 🔐 **Yönetici & Komuta Paneli (`/admin`):**
  - Personel ekleme, düzenleme, silme, şifre ve rütbe yönetimi
  - Canlı istatistik sayaçları
  - Geliştirici ve sistem ayarları yönetimi
- 🔔 **Canlı İstatistikler & Duyurular:** Departman aktiflik göstergeleri, son haberler ve basın bültenleri.

## 🚀 Kurulum

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları izleyin:

```bash
# 1. Projeyi klonlayın
git clone https://github.com/Luzzysxdd/fivem-legalwebsite.git

# 2. Proje dizinine gidin
cd fivem-legalwebsite

# 3. Bağımlılıkları yükleyin
npm install

# 4. Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızdan **`http://localhost:3000`** adresine giderek siteyi görüntüleyebilirsiniz.
